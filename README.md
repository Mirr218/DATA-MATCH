# DATA MATCH: прогноз спроса на билеты ХК «Авангард»

Решение прогнозирует полное число обычных билетов для 17 будущих матчей
в восьми ценовых зонах. Результат — 136 целых чисел в порядке шаблона организаторов.

## Состав решения

- `notebooks/Avangard_ticket_demand.ipynb` — самостоятельный ноутбук: описание задачи,
  подготовка данных, выбранная модель, временная проверка и сборка прогноза.
- `outputs/predictions.csv` — итоговый файл для сдачи.
- `requirements.txt` — версии библиотек.

Исходные файлы организаторов располагаются в `data/`: `matches.csv`, `zones.csv`,
`sales_daily.csv`, `submission_template.csv`. Они не входят в код решения.
Данные и код используются только для хакатона; код передаётся только жюри.

## Запуск

Расчёт проверен на Python 3.12.14. Из корня проекта:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Откройте ноутбук в Jupyter или VS Code, выберите Python из `.venv`
и выполните все ячейки сверху вниз. Запуск возможен из корня проекта
или папки `notebooks`. Он создаёт `outputs/predictions.csv`.
Предварительно рассчитанные таблицы и дополнительные модули не нужны.

## Модель

Основной прогноз — сглаженное среднее зоны в текущем сезоне плюс линейная
Ridge-поправка календаря и соперника. Признаки: зона, соперник, день недели,
месяц, время начала и номер домашнего матча в сезоне.

Для шести матчей с открытыми продажами добавляем половинную поправку раннего
темпа. Её связь с итогом учится на завершённых исторических матчах,
сопоставленных по числу дней до начала игры. Для остальных одиннадцати
матчей используется основной прогноз. Формулы и параметры объяснены в ноутбуке.

## Проверка и результат

Окна: M035–M051, M052–M068 и M069–M085. Обучение использует только матчи
до начала окна, завершённые к соответствующему утру прогноза; все восемь
зон одного матча остаются вместе. Продажи обрезаются строго до утра прогноза.

| Метод | Общая ошибка окна 1 | Окна 2 | Окна 3 | Сводный S |
|---|---:|---:|---:|---:|
| Среднее по зоне | 154.386 | 104.542 | 148.846 | 139.155 |
| Ridge + ранние продажи | 149.613 | 71.426 | 142.952 | 126.736 |

Общая ошибка каждого окна смешивает квадраты ошибок сценариев без продаж
и с продажами с весами 11/17 и 6/17. S усредняет ошибки окон с весами
0.25, 0.25 и 0.50. Улучшение относительно среднего по зоне — 8.92%.
Обе сценарные ошибки, ошибки по зонам и диагностика длительности продаж 28–42 дня приведены в ноутбуке.

Все три окна использовались для выбора метода и параметров. Независимого
проверочного набора нет; реальный RMSE скрытых 136 строк неизвестен.

В итоговом файле прогноз округлён до целого и ограничен уже проданным
и вместимостью `seats − season_tickets`. Момент прогноза — утро 15.12.2025,
продажи доступны по 14.12 включительно. Внешние данные не используются.
