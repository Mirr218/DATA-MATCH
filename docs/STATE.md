## Решение по ранним продажам
- **Оставить baseline.** A (дни от открытия): S = 201.637; B (дни до матча): S = 214.933 против 139.155. Оба не прошли все четыре условия: ни одного улучшенного окна; превышены пределы S, последнего R и сценария с продажами. Сценарий без продаж полностью сохранён.
- Общая формула A/B: sold / средняя историческая доля; возврат к baseline при <5 аналогах или доле <0.15, включая отсутствие аналогов/нулевую долю. Правила после запуска не менялись. Возвраты: 27 дней — 0% у обоих; 7 дней — A 7.986%, B 42.708%.
- Результаты A/B выше относятся к прежней проверке без верхнего ограничения; записи и решения сохранены, пересчёта после seats не было.
- C отклонён: S=149.200 против 139.155, улучшенных окон 0/3; R последнего окна 156.937 >153.311, S[1]=156.980 >133.640. Без продаж baseline сохранён. Возвратов 0/288 на каждой отсечке, ограничений дня аналога 0/2395. Параметры C после результата не менялись.
- Один дополнительно разрешённый эксперимент C завершён 6 октября; эксперименты закрыты, остаётся baseline. Следующий этап — комплект сдачи. КХЛ, абонементы, праздники и внешние данные не использовались.
