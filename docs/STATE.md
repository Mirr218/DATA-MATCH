# Текущее решение

- Работа ведётся в существующем worktree develop; основную папку main не переключать.
- Единственный ноутбук: notebooks/Avangard_ticket_demand.ipynb. Он самодостаточен, src не нужен.
- Итог: outputs/predictions.csv, 136 целых прогнозов; Run All воспроизводит его из сырых CSV.
- Модель: сезонный уровень зоны (prior=8), Ridge(alpha=10), поправка ранних продаж весом0.5.
- Аналоги по дням до матча, L>=28, минимум5; общий коэффициент ограничен[0,3].
- Окна M035–051/M052–068/M069–085, моменты O/O+7/O+27, веса и границы PROTOCOL сохранены.
- Сценарный S модели126.735841108, среднего по зоне139.154980934; улучшение8.9247%.
- Все3окна участвовали в выборе; независимого теста нет. Итоговые исторические абонементы исключены.
- Старые варианты, записи их экспериментов и резервные файлы удалены по прямой просьбе человека.
- После редакторской переработки все984 исторических прогноза и итоговый CSV совпали с выбранным решением.
- README и requirements.txt описывают воспроизведение; в финальном ноутбуке нет служебной логики.
- Данные организаторов не изменялись; коммитов, push и публикации нет.
