# Проверка выбранного решения

## Ridge с поправкой ранних продаж

- Модель: сглаженный сезонный уровень зоны, Ridge(alpha=10) на отклонениях обучающих
  ответов, аддитивная поправка ранних продаж с весом0.5. Сила сезонного сглаживания8.
- Гипотеза: собственные ранние продажи дополняют расписание информацией о спросе
  конкретного матча. Аналоги сопоставляются по одинаковым дням до игры.
- Проверка: M035–M051/M052–M068/M069–M085. Сценарий без продаж — утро открытия,
  все17 матчей окна; с продажами — общая выборка L>=28 (10/17/9), утро O+27/O+7,
  веса2/3 и1/3 внутри пары. История до окна и завершённая к утру прогноза.
- Ограничения: округление .5 вверх, минимум sold; исторический максимум seats,
  test максимум seats-season_tickets. Исторические финальные абонементы исключены.
- RMSE без продаж:156.284878460/73.739705164/150.870635080.
- RMSE с продажами:136.536426763/66.975961447/127.161587928.
- Общие R:149.612788575/71.425675794/142.952450032; S126.735841108.
- Среднее по зоне на тех же примерах: R154.386435738/104.541882470/148.845802765;
  S139.154980934. Улучшение8.9247%; ошибка меньше во всех трёх окнах.
- RMSE по зонам1..8 выводится в таблице notebook, из фактических ошибок тех же примеров.
- Вывод: выбран описанный вариант. Все три окна использованы для выбора;
  независимого теста нет, ошибка скрытого test неизвестна.
- Редакторская переработка: новый самостоятельный notebook воспроизвёл все984
  исторических прогноза и итоговый CSV без изменений. Около20с на полный расчёт.
