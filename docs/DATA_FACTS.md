# Факты, используемые в решении

- В matches.csv102 матча: train M001–M085 и test M086–M102; восемь зон каждого матча.
- Цель — сумма tickets по дням пары матч–зона. Отсутствующая дневная запись означает0 продаж.
- Данные предоставлены на утро15.12.2025; дневные продажи заканчиваются14.12.2025.
- M086–M089: известны27 календарных дней продаж; M090–M091:7 дней; M092–M102 без продаж.
- Длительность продаж — (date-sales_open).days; train10–63 дня, test28–42 дня.
- Предоставленная граница test: seats-season_tickets; финальные исторические абонементы не являются признаками.
- Исторический seats используется как вместимость по согласованному допущению PROTOCOL.
- khl_games.csv заканчивается19.11.2025, хотя README организаторов обещает15.12.2025.
  КХЛ не входит в выбранную модель; имя соперника берётся из расписания.
- Во временной проверке с продажами общая выборка L>=28 содержит10/17/9 матчей.
