# Индекс аудитов и диагностических отчётов

Отчёты сохраняют даты, исходные номера строк кода и результаты проверенных версий. Текущие решения — [STATE](../STATE.md), действующие правила — [PROTOCOL](../PROTOCOL.md), хронология — [EXPERIMENTS](../EXPERIMENTS.md).

| Отчёт | Область проверки и вывод |
|---|---|
| [DATA_FACTS_AUDIT.md](DATA_FACTS_AUDIT.md) | Исходные утверждения о CSV; найдены и исправлены расхождения, «НЕТ» относится к исходной версии DATA_FACTS. |
| [BASELINE_SCENARIOS_AUDIT.md](BASELINE_SCENARIOS_AUDIT.md) | Сценарные примеры и оценка baseline; временные границы и расчёт sold подтверждены, утечек нет. |
| [BASELINE_SUBMISSION_AUDIT.md](BASELINE_SUBMISSION_AUDIT.md) | Диагностика и сборка baseline-файла; формат и границы test подтверждены, скрытая точность неизвестна. |
| [LEAKAGE_AUDIT_FINAL.md](LEAKAGE_AUDIT_FINAL.md) | Итоговая проверка baseline и сохранённого файла; внутренним метрикам и формату можно доверять в описанной схеме. |
| [EARLY_SALES_AUDIT.md](EARLY_SALES_AUDIT.md) | Фиксированные кандидаты A/B без исторического потолка; утечек нет, оба отклонены, сохранён baseline. |
| [PACE_RATIO_AUDIT.md](PACE_RATIO_AUDIT.md) | Фиксированный C с общим ограничением seats; независимое восстановление совпало, C отклонён, сохранён baseline. |

Обозначения A/B/C в старой диагностике baseline описывают варианты выборки и границ; это отдельные обозначения, отличающиеся от кандидатов по темпу продаж. При использовании отчёта важны его дата и область проверки.
